¿Qué es este panel?
Controla el servidor Revit MCP: el proceso local que conecta EstimaStruct con Revit a través del bridge pyRevit. Desde aquí levantas/detienes ese proceso, ejecutas scripts de sincronización y ves su salida en la consola — sin salir de la app.
Botones del encabezado
⚡ Levantar MCP — inicia el proceso del servidor MCP en tu máquina.
■ Detener MCP — apaga el proceso (los scripts vía MCP dejarán de funcionar).
↺ Refrescar — vuelve a consultar el estado (proceso, documento Revit, bridge).
✕ Cerrar — cierra el panel; el servidor sigue corriendo si estaba arriba.
El punto junto al título resume el estado: ● arriba, ● abajo.
Python offline vs IronPython vía MCP
PY Python offline: corre fuera de Revit (CPython). Trabaja sobre CSVs exportados y la BD de EstimaStruct. No necesita Revit abierto ni el MCP levantado.
IP IronPython vía MCP: snippet inyectado dentro del proceso de Revit por el bridge pyRevit. Requiere MCP arriba y un documento abierto en Revit.
⚠ DEPRECADO marcado así = existe un reemplazo; evita usarlo en flujos nuevos.
Obra activa y Schedule CSV
Obra activa = el presupuesto de EstimaStruct sobre el que actúan los scripts (destino de cantidades y partidas). Schedule CSV = el archivo exportado desde Revit (botón "Exportar Schedules") que sirve de fuente. Selecciona ambos antes de pulsar ▶ Ejecutar; si un script no aplica a una obra, ignora la selección.
Cómo leer la consola
Cada línea abre con timestamp en gris. Verde = operación exitosa; rojo = error (revisa el mensaje completo, suele incluir el traceback); amarillo = información/progreso. "⌫ Limpiar" borra la vista, no detiene nada.

About EstimaStruct

EstimaStruct es una plataforma open source de estimación para ingeniería y arquitectura, diseñada para análisis estructural, detalle técnico y control de costos con trazabilidad.

Funciona como puente entre Revit 2027 y el análisis de precios dentro del ecosistema Estimbot, convirtiendo schedules y datos de obra en partidas auditables y listas para presupuesto real.

Construida con FastAPI, SQLite y Vanilla JavaScript para priorizar portabilidad, transparencia y despliegue simple en equipos técnicos.

  • Estimación por partidas, capítulos CSI e insumos
  • Importación de cantidades desde Revit schedules
  • Base pensada para compartirse, auditarse y descargarse desde GitHub
  • Parte del módulo de automatización de Estimbot
