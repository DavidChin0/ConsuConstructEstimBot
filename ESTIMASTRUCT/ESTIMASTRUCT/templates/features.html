¿Qué es EstimaStruct?

EstimaStruct integra diseño estructural, importación de cantidades desde Revit/ETABS y generación de presupuestos en una aplicación local. Reemplaza hojas de cálculo manuales con un pipeline reproducible ficha → partida → capítulo → presupuesto, manteniendo trazabilidad completa de fórmulas y auditoría de precios.

Módulos Principales

📊

Presupuesto

Motor de estimación por partidas CSI MasterFormat. Integra catálogo de fichas con costos históricos (mano de obra, materiales, sub-matrices OPUS) y overhead configurable (administración, utilidad, imprevistos, IVA).

  • CRUD presupuestos + plantillas versionadas
  • Capítulos agrupados por CSI (Div 00–33)
  • Partidas con cantidad, unitario, total
  • Bucketing 3-vías (MO, MA, Sub-matriz)
  • Cálculo de PU = base × (1 + sobrecosto%)
  • Export XLSX, PDF, Portal Supabase
Stack: FastAPI + PostgreSQL · Decimal(4dp) ROUND_HALF_UP
🗺️

Viewer 3D

Visualizador de modelos BIM en 3D. Lee archivos GLB exportados desde Revit y renderiza con Babylon.js, permitiendo inspección geométrica completa del proyecto sin abrir Revit.

  • Renderizado Babylon.js (WebGL)
  • Navegación 3D fluida (pan, zoom, rotación)
  • Modelos desde Revit (exportar como GLB)
  • Texturas PBR (diffuse, normal, roughness)
  • Soporte for furniture + structural elements
  • Perf optimizado para localhost
Stack: Babylon.js · WebGL · GLB assets
🗂️

Base de Datos

Repositorio central de cantidad, precios y insumos. PostgreSQL primario (desde 2026-07-20) con soporte legacy SQLite. Mantiene integridad transaccional y auditoría de cambios.

  • Postgres primario (:5432), SQLite compat
  • ORM SQLAlchemy 2.0 + Alembic migrations
  • Recursos (catálogo maestro precios)
  • Insumos por partida (rebucketing automático)
  • Backup/Restore ZIP (portable)
  • UUID PKs, Decimal money, ACID
Stack: PostgreSQL 16 · SQLAlchemy · Alembic
📐

Diseño Estructural

Suite de cálculo para concreto reforzado (ACI 318) y acero estructural (AISC 360-16 LRFD). Genera automáticamente partidas CSI para concreto, acero y encofrado.

  • Concreto: vigas, columnas, losas (CHOC-08)
  • Acero: perfiles LRFD, conexiones (§J)
  • Cálculo de refuerzo (As, Av/S, At/S)
  • Takeoff: volumen concreto, peso acero, área encofrado
  • Import de ETABS (combos, cargas últimas)
  • Fórmulas con notación Mathcad (KaTeX)
Stack: Python calculo_* · KaTeX rendering · Pydantic
📅

Cronograma

Generador de gráficos Gantt a partir de rendimientos y cuadrillas. Calcula duración de actividades y prorrateo a valor de banco.

  • Overrides MO diario (n_esp, n_ay)
  • Cálculo automático de duración
  • Cadena crítica + buffers
  • Export XLSX (compatible MS Project)
  • Prorrateo a valor para financiamiento
  • UI interactiva (drag, edit, delete)
Stack: FastAPI + openpyxl
🔍

RAG Retrieval

Búsqueda semántica sobre documentación y especificaciones de proyecto. Semantically integrado con fichas CSI y notas técnicas.

  • Indexación semántica de partidas
  • Búsqueda por descripción, CSI, keywords
  • Filtro por unidad, tipo de insumo
  • Integración con catálogo maestro
  • Sugerencias de fichas similares
  • Auditoría de resultados (relevancia)
Stack: Full-text search + vector embeddings

Integraciones MCP (Model Context Protocol)

🔧 Revit MCP

Integración bidireccional con Revit 2027 a través de bridge pyRevit. Inyecta IronPython dentro del proceso de Revit para automatizar extracción de cantidades, generación de keynotes y sincronización de propiedades.

POST /revit-mcp/start
GET /revit-mcp/status
POST /revit-mcp/import-quantities
POST /revit-mcp/generate-keynotes
Caso de uso: Extracción automática de cantidades Abre un modelo Revit, selecciona elementos (vigas, columnas, losas). El MCP exporta schedules (CSV), EstimaStruct parsea e importa cantidades automáticamente en la tabla de presupuesto, mapeando por Type Mark o CSI keynote. Acelera takeoff de horas a minutos.
Requisitos: Revit 2027 + pyRevit instalado · Puerto 8100 libre · Windows 11

🏗️ ETABS Integration

Parser CSV para modelos de ETABS (CSi). Importa resultados de análisis sísmico (fuerzas últimas, momentos, cortantes) y alimenta directamente el motor de diseño estructural (CHOC-08, acero LRFD).

POST /etabs/import-results
POST /etabs/parse-csv
GET /etabs/spectrum-export
Caso de uso: Diseño sísmico integrado Exporta resultados de análisis ETABS (Concrete Frame Design, combos sísmicos). EstimaStruct parsea CSV → crea elementos de diseño + casos de carga → calcula automáticamente refuerzo (As, Av/S) y genera partidas CSI 03 (concreto) + 05 (acero). Cierra el loop análisis → diseño → presupuesto sin reescrituras.
Formatos soportados: CSV (Concrete Design export) · XLSX schedules · Unidades: kgf, kN, ton

Backend

FastAPI 0.111 · 24+ routers especializados (presupuestos, partidas, insumos, diseño, export).
Uvicorn 0.29 ASGI server en :8002.
Pydantic 2.7 validación de requests.

Base de Datos

PostgreSQL 16 primario (desde 2026-07-20).
SQLAlchemy 2.0 + Alembic migrations.
SQLite legacy para backup/export.

Frontend

Flask 3.1 server-rendered templates + Jinja2.
Vanilla JS modular (core.js, app.js, calculo-estructural.js).
KaTeX para rendering de fórmulas matemáticas.

Rendering

Babylon.js viewer 3D (WebGL).
ReportLab 4.5 + Chromium headless para PDF con membrete.
openpyxl 3.1 para XLSX export.

Integraciones

Revit MCP HTTP :8100 (pyRevit bridge).
ETABS CSV parser (sísmico, concreto, acero).
Supabase REST para Portal público.

Runtime

Python 3.x + Windows 11 PowerShell launcher.
PostgreSQL Windows service.
CORS local (sin auth — localhost only).

Deployment Local

EstimaStruct está optimizado para ejecución local en Windows 11. Coordina dos procesos (FastAPI + Flask), PostgreSQL y opcionales (Revit MCP, ETABS).

START_POSTGRES_UNICA.ps1 ├─ git pull origin main ├─ Lee D:\Secrets\postgres_credentials.txt ├─ export ESTIMASTRUCT_DATABASE_URL=postgresql+psycopg://... └─ START_UNICA.ps1 ├─ Kill-Port 5000 / 8002 (recursivo) ├─ Borra __pycache__ (limpieza) ├─ Verifica deps ├─ Job "back": uvicorn backend.main:app :8002 └─ Job "front": python ESTIMASTRUCT/app.py :5000

⚠️ No usar START_UNICA.ps1 directo — levanta SQLite legacy sin variables de Postgres.
